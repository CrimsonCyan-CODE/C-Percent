# C-Percent
C% is an esoteric programming language with a mix of Assembly, C and Python-like syntax, built around &lt;&lt; chaining and short keywords like ptx, stin and gback. It has variables, lists, loops, if/elseis/els, custom commands, dice rolls, math, try/catch and file I/O. Includes a Python interpreter: python cpercent.py program.cpc
